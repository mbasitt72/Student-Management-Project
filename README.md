# Student-Management-Project

A beginner python program suited and designed to incubate the everyday management of the students in an institute.

## Feature:
 Adds Student Information

 Stores Student Names
 
 Stores Roll Numbers
 
 Stores Courses
 
 Stores Contact numbers
 
 Stores Class ID
 
 Displays all the records in the file
 
 Displays all the Info in chronological order
 
 Searches every record precisely
 
 Uses the Roll no as the primary key
 
 Gives an error message when incorrect Roll no is entered
 
 Gives an option list for what you want to access
 

## Language
 Python
